# Launchly Element Library

This reference documents 589 entries in the editor palette and 23 built-in section blocks. The palette catalog is the source of truth for the current names, IDs, and short purposes. All current palette entries are available in the editor. Some entries are rendered as configurable starter blocks; external services, payments, form storage, or account behavior need their matching integration to be configured before production use.

## How to use this guide

- **Purpose** describes the job the element is intended to do.
- **Use case** gives a practical place to use it on a site.
- **Palette ID** is the stable editor catalog key.

## Practical notes

- Buttons should be configured with a destination or action in the button inspector. Page and anchor links stay within the site; email, phone, WhatsApp, Telegram, Discord, download, and back-to-top actions use their matching URL behavior.
- Product, cart, checkout, booking, account, analytics, and third-party embed elements may show a useful demo state until the corresponding data source or service is connected.
- Give images meaningful alt text, label form controls, and check keyboard access and contrast before publishing.
