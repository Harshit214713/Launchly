# Security Policy

## Supported Versions

We actively support and release patches for the latest version of Launchly.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Launchly team takes the security of our platform and users seriously. If you believe you have discovered a vulnerability, please report it responsibly:

1. **Do not** create a public GitHub issue.
2. Email or privately message the repository owner via GitHub Security Advisories or at:
   - GitHub: [@simplyvardaan](https://github.com/simplyvardaan)
3. Please include:
   - A description of the issue and potential impact
   - Step-by-step reproduction instructions or a minimal proof of concept (PoC)
   - Mitigation suggestions (if available)

### What to Expect

- **Acknowledgment**: You will receive an initial response acknowledging your report within 48 hours.
- **Assessment**: We will evaluate the vulnerability and keep you updated on progress.
- **Fix & Disclosure**: Once patched, we will publish an advisory and publicly acknowledge your contribution (unless you request anonymity).

Thank you for helping keep Launchly and our open-source community secure!
